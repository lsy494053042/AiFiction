# AiFiction 项目进度

最后更新：2026-03-27

## 1. 当前项目目标

当前项目目标已经收敛为：构建一个“本地正文驱动、自动维护优先、人工审查兜底”的个人网文控制台。

这意味着：
- 不再把重点放在手工录入型后台。
- 不把重点放在一开始就做复杂 Agent 协作。
- 优先把数据底座、增量同步、自动维护和审查机制做稳。

## 2. 当前所处阶段

当前阶段：**阶段 4.5：产品收口与自动化减负**

阶段判断：
- V2 数据底座可以继续承载后续改造。
- 当前改造属于增量演进，不需要推倒重建数据库。
- 自动同步、待审查和首版事实回写已经接入 Web 工作台。
- 首页书架入口和详情页分区式工作台都已经落地，当前最紧急的问题转向审查机制与低风险自动通过。

## 3. 已完成内容

### 3.1 数据底座
- SQLite 已接入。
- V2 schema 已落地。
- 自动同步相关 V2 表已进入 schema 与 migration。
- `db:v2-smoke`、`db:sync-smoke` 已可稳定运行。

### 3.2 自动同步基础设施
- 已新增同步源仓储。
- 已新增同步工作流仓储。
- 已新增项目目录同步服务。
- 已新增审查队列服务。
- 已新增通过候选的事实回写服务。
- 已新增 Worker 目录同步入口。
- 已支持：列作品、列目录源、绑定目录、执行扫描。
- 已支持：对新增 / 修改文件生成摘要预览 artifact。
- 已支持：对新增 / 修改文件生成结构化抽取预览 artifact。
- 已支持：写入 `asset_updates_v2` 与 `review_queue_v2`。
- 已支持：对审查项执行“通过 / 驳回”并回写状态。
- 已支持：把通过的角色、关系、伏笔、时间线候选写入结构化事实层。
- 已支持：为未手工建章的源文档自动补占位卷 / 占位章节映射。

### 3.3 Web 工作台
- 首页可读取 V2 作品概览。
- 首页已重构为“导航 + 书架 / 列表 + 搜索”的工作台入口。
- 作品详情页已拆成“总览 / 待处理 / 剧情资产 / 高级维护”分区式工作台。
- 逐条编辑卷 / 角色 / 章节的入口已经被后置到资产概览和高级维护里。
- 手工维护兜底入口继续保留，但默认不打扰“总览”和“待处理”两个主视图。

## 4. 当前未完成的关键项

### P1

## 5. 下一阶段建议顺序

1. 先把审查机制收口成“变更包 + 风险分层”。
2. 再推进低风险自动通过，继续压缩手工入口。
3. 然后补来源引用与冲突处理。
4. 再做关系图谱与事实级引用展示。
5. 最后再接更真实的模型抽取和影响分析。
