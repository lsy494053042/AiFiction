# 写作风格与猎人味道

## 当前执行版：先让人读懂

这本书首先是网文，不是谜语文，也不是设定氛围稿。

正文的第一要求是让没看过《全职猎人》的读者也能跟住：现在在哪、谁要什么、为什么动手、主角知道了什么、下一步为什么非走不可。看过原著的读者可以多一层会心，但不能靠原著记忆才能看懂正文。

### 基本写法

- 用大白话写清楚事情，不用似是而非的主题词撑味道。
- 少造黑话。正文里第一次出现的本地说法，要么从动作里看得懂，要么马上补一句明白话。
- 不把“残酷”“灰色”“规则感”挂在嘴上。写谁饿了，谁被卖了，谁欠了半碗汤，谁为了背风地方动手。
- 不用一串概念词总结世界，例如“价、账、货、路、祸、命”这种写法禁止当作风格口号。
- 不用“看似有味”的谜语句替代解释。该说清楚时就说清楚。

### 设定怎么讲

设定必须讲，但要跟着晏决的视角讲。

- 晏决已经从原主记忆里知道的常识，可以直接写出来。
- 晏决不知道的东西，不能让旁白提前全知道。
- 眼前剧情需要读者理解的东西，必须及时解释。
- 复杂体系分批讲：先讲当前能用到的部分，后面遇到更深场景再补。
- 解释可以来自原主记忆、人物对话、晏决观察、吃亏后的复盘。

例如：

- 流星街第一次展开时，要让读者知道这里靠外面倒货、倒尸、倒麻烦活着，不只是“很惨”。
- 念能力前期可以先写成异常感知，但不能十章之后读者还不知道这是这个世界里真实存在的一种力量。
- 白箱线出现时，要让读者知道它不是普通垃圾，有人找它，见过它的人会被盯上。
- 猎人协会、念、旅团、黑市、灰渡等原著或原创体系第一次真正影响剧情时，都要给到当前剧情所需的明白解释。

### 场面怎么写

每章先确定一个具体事情。

可以是抢箱、喝汤、送东西、抢棚子、试牌、偷听、逃跑、换船位、接活。先把这件事写清楚，再让世界观从事情里冒出来。

一章里读者至少要拿到一个实在信息：

- 这个地方怎么运转。
- 这个人靠什么活。
- 这件东西为什么危险。
- 这个能力能做到什么，做完有什么消耗。
- 主角下一步为什么要这么走。

### 句子禁区

以下写法默认先删：

- 先抛一句判断，再补一段解释。
- “不是……而是……”连续使用。
- “这是……是……是……”排比。
- 章尾强行深沉，例如“谁都一样”“命也一样”。
- 用“算、多半、通常、不算、像是”拖虚句子。
- 作者替人物下定义。
- 作者替读者总结“这就是流星街的规矩”。

如果一句话能换成具体事，就换成具体事。

错：这就是流星街最赤裸的价码。  
对：小孩被带走后，坡下有人说赚了半袋饼，也有人把自家孩子往身后拽。

错：黑蜡牌换路，也换祸。  
对：这牌子能让人离开流星街，也会把找牌的人引到他身上。

错：小钳抢的是命。  
对：小钳抢棚子，因为外头那阵风能把人冻死。

### 人物和对白

人物说话要先有目的，再有味道。

- 煤婆说话是为了做买卖、记人情、守灶口，不是为了讲人生。
- 朽木说话是为了判断人能不能用，不是为了装高深。
- 小钳说话是为了活、抢位置、试探晏决，不是为了当反派。
- 砾说话可以快，可以占便宜，但不能只负责活跃气氛。
- 晏决可以冷静，但不能端着。他问，是因为要弄清楚；他沉默，是因为没必要说。

对白里可以讲设定，但必须是人物当下有理由讲。

### 人物互动

不要用“跟团 / 不跟团”“避开 / 不避开”“埋点 / 不埋点”这种二选一模板处理人物。

晏决是活人，有目的，也有喜恶和判断。是否互动，只看当场是否需要：

- 对方会不会影响他当前目标。
- 对方能不能借力。
- 对方会不会坏事。
- 对方是否危险到必须避开。
- 这次交互是否会改变双方局面。

他观察别人，是燕青的眼力和活命习惯，不是替读者点评角色。看脚步、呼吸、眼神、手、站位、是否藏力，最后都要回到一件事：这人对当前局面有什么用，或者有什么危险。

不要强行写“理解”“认同”“被打动”。人物可以有内核，但正文不要替他上价值。门淇、小杰、西索、酷拉皮卡等人都按当前目的和风险处理，读者能自己看出他们是什么人。

杀与不杀也不是道德模板。需要杀、能承受后果，就杀；杀了会输、会暴露、会浪费体力，就不杀。最终面试不杀，是因为规则限制，不是因为晏决变成好人。

### 念能力写法

前期写念，不要写成玄乎气氛，也不要写成游戏技能。

读者要逐步知道：

- 这个世界有人能使用一种看不见的力量。
- 晏决现在不是正常学习，而是身体出了问题，像破口漏气。
- 乱碰残留会反震，会疼，会虚。
- 真正的基础训练、体系名称和能力分类，要在有人教、有人点破、或者晏决吃亏后补清楚。

能力只在改变行动结果时出现。不能单独摆设定。

### 章尾怎么收

章尾不要写作者判词。

更适合的收法：

- 留一个具体后果。
- 多一个人盯上晏决。
- 某个小人物做了选择。
- 某件东西被证明确实危险。
- 晏决得到一个新问题，但读者知道问题是什么。

不要靠抽象词收尾。让事情本身停在那里。

## 总口径

本书要尽量写出《全职猎人》世界的味道，但不直接模仿漫画台词、分镜句式或具体桥段。

要学的是叙事机制：

- 人物按自己的欲望和判断行动。
- 世界不替任何人讲道理。
- 规则清楚，例外危险。
- 战斗是信息、判断、心理、身体和能力的混合。
- 温情存在，但不抹掉残酷。
- 荒诞存在，但不削弱后果。

## 猎人味道的核心

### 规则感

猎人的好看不在于能力名字多，而在于规则具体。

写念能力、黑市交易、流星街规矩、猎人考试外围、船队规矩时，要先让读者知道：

- 这件事怎么运转。
- 谁从中获利。
- 谁会因此死。
- 有没有漏洞。
- 晏决看见了哪一个漏洞。

规则可以后置完整解释，但不能后置基础理解。

### 信息差

信息不能一次倒完。

每一章最好只推进一种核心信息：

- 一个地名的用处。
- 一个势力的运转方式。
- 一个角色的真实价码。
- 一个能力的限制。
- 一个传闻背后的漏洞。

读者知道原作，但晏决不知道。正文的爽点不是“主角提前知道”，而是“他在有限信息里读出了别人没读出的东西”。

### 冷静旁白

旁白要克制。

它可以说明事实、规则、后果和误判，不要替人物喊价值观。

适合的旁白方向：

- 某种流星街规矩的实际后果。
- 某个念能力动作的条件。
- 某个人为什么在那一秒判断错。
- 一笔交易表面价格和真实价格的差别。

避免：

- 反复强调自由、救赎、命运。
- 大段解释主角多特别。
- 用作者声音替角色评判善恶。
- 现代吐槽。

### 角色驱动

每个重要人物都要像自己活着。

晏决不出现时，砾会继续找饭，小钳会继续抢位置，煤婆会继续记账，朽木会继续看价，白箱公司会继续收货。

正文推进来自人物目的碰撞，而不是角色排队给主角送剧情。

### 灰色底色

残酷不是冷脸台词，也不是一直死人。

残酷来自：

- 好人也会标价。
- 坏人也可能讲规矩。
- 温情常常带账。
- 弱者也会害人。
- 强者不一定解释。
- 选择能救一个人，也会害另一个人。

不能为了冷而冷。真正的灰色，是每个人都有自己的理由，但理由不等于免罪。

### 奇异感

猎人世界要有奇怪的人、奇怪的职业、奇怪的规则。

但奇异不能只是装饰。

一个奇怪设定至少要承担一项功能：

- 给晏决提供新情报。
- 给能力开发提供场景。
- 给人物选择制造压力。
- 接到势力、历史或后期入口。

## 章节写法

### 单章结构

每章尽量有一个明确的“读者所得”。

常用结构：

1. 先给一个具体场面。
2. 让人物带着目的进入。
3. 中段揭示一个规则、误判或价码。
4. 末尾给出新压力或新选择。

不要每章都写成大事件。猎人味道里，小规则、小交易、小误判也能撑住一章。

### 章尾钩子

章尾不要总靠“来人了”“危险来了”。

可用钩子：

- 信息反转：读者刚理解的规则被补上一条更狠的例外。
- 价码反转：看似便宜的东西其实最贵。
- 人物反转：某人不是变坏，而是暴露了本来就在做的事。
- 能力反转：玲珑花绣能做到一件事，但代价是暴露另一件事。
- 世界反转：小事件露出大势力边角。

### 对话

对话要短，带目的。

人物说话时要考虑：

- 他想得到什么。
- 他想隐瞒什么。
- 他知道对方不知道什么。
- 他害怕哪一句话被听懂。

避免：

- 长篇自白。
- 现代网络梗。
- 所有人都用同一种聪明腔。
- 角色替作者解释设定。

### 旁白和解释

念能力解释可以精准，但不要像游戏说明书。

可以用：

- 战斗中发现。
- 交易中被点破。
- 失败后复盘。
- 老手只说半句。
- 晏决误解后修正。

## 战斗写法

### 打戏核心

玲珑花绣的战斗爽点不是线多强，而是晏决怎么把场面缝成自己的局。

一场战斗至少要写清：

- 晏决先看见了什么。
- 对手有什么目的和优势。
- 场地里哪些东西可用。
- 晏决布了哪几处线。
- 对手在哪个瞬间误判。
- 晏决如何用身体、相扑、短刃、暗器或地形收口。
- 胜利留下什么代价或后果。

### 念能力层级

普通念能力只有条件、限制、范围、消耗和反制。

只有制约与誓约才有真正代价。

晏决前期不能靠玲珑花绣碾压强者。

对弱者，他靠线能制造优势。

对老手，他的线只能制造机会。

对真正强者，他必须先活下来，能拿到一点信息就已经是收获。

### 失败和代价

晏决可以聪明，但不能每次都算尽。

允许：

- 线被发现。
- 布局被破坏。
- 情报买错。
- 人情欠下。
- 救一个人导致另一个人被卖。
- 杀人后引来更大的账。

失败不是削弱主角，而是让世界可信。

## 镜头感

可以参考漫画和动画的镜头节奏：

- 一个物件特写承载信息。
- 一个停顿让危险变重。
- 一句短话压住长解释。
- 战斗中切换“动作”和“判断”。
- 大场面前先写小声音、小动作、小价码。

但正文不是分镜脚本。镜头感要服务阅读，不要写成镜头说明。

## 本书禁区

- 不写现代穿越者吐槽。
- 不写“原作剧情开始了”。
- 不让晏决按读者知识行动。
- 不让原作人物为晏决降智。
- 不把流星街写成纯黑背景板。
- 不把灰色写成装酷。
- 不把念能力写成游戏技能。
- 不把小人物写成一次性工具。
- 不为了贴近原作而复刻原作桥段。
