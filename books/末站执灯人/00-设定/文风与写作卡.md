# 文风与写作卡

这份卡只服务《末站执灯人》。

它的作用不是限制正文，而是保证后面继续写第二章、第三章、卷一后半段时，整本书的味道、人物声音和推进节奏不散。

## 1. 这本书的核心气质

- 整体气质：冷硬、潮湿、废旧、压抑，但不故作文艺
- 类型手感：都市废土、轨道遗迹、灯塔规则、悬疑成长
- 情绪温度：偏冷，偶尔发热，但不长期高燃
- 阅读体验：先让读者感到“不对劲”，再一点点看清规则和代价

## 2. 文风基线

### 句子策略
- 以短句和中短句为主
- 异常出现、章末逼迫、动作决断时，句子必须更短、更硬
- 只有在站台、黑雨、旧轨、残灯这种高氛围场景里，才允许放长句压气氛

### 描写重点
- 先写具体物，再写感觉
- 先写代价，再写玄
- 先写现实处境，再写宏大秘密

### 常用意象
- 灯
- 轨
- 铁
- 锈
- 雨
- 站台
- 油污
- 冷风
- 旧电流

### 不该滥用的表达
- 不要连续堆抽象比喻
- 不要频繁“像命运”“像深渊”“像无形大网”
- 不要用空洞大词代替现场细节

## 3. 林野声音卡

### 他看世界的顺序
1. 先看代价
2. 再看危险
3. 然后判断值不值得冒险
4. 最后才谈理想和道义

### 人物底色
- 底层修补工出身
- 活得不轻松，天然对权力和秩序保持警惕
- 不是热血笨冲型
- 本能是先保命，但又不是彻底冷血

### 说话方式
- 句子短
- 不爱解释
- 有防备感
- 带一点硬刺，但不贫嘴

### 动作与反应规律
- 遇到异常时，先观察细节，再决定动不动
- 先怀疑，再行动
- 情绪不直接倾倒，通常通过动作、停顿和判断露出来

### 绝对不能写崩的点
- 不能突然变成话很多的人
- 不能遇事先喊口号
- 不能一上来就对古文明真相表现出过度浪漫化兴趣
- 不能轻易信任任何靠近灯塔秘密的人

## 4. 乔宁声音卡

### 她的功能
- 不是温柔陪跑型女主
- 是信息差制造者、引线人、压迫林野做选择的人

### 说话方式
- 稳
- 冷
- 短
- 话常常只说七分

### 和林野的互动张力
- 旧相识，但不彻底信任
- 她知道得更多，却不轻易说透
- 她给出的帮助，总带一点代价和试探

### 绝对不能写崩的点
- 不能写成热闹嘴碎型
- 不能轻易把秘密讲透
- 不能太早进入明显暧昧腔调

## 5. 关系张力基线

### 林野 x 乔宁
- 起点不是甜，不是轻松拌嘴
- 起点是互相试探、互相利用、夹着旧账
- 关系推进应该是：不信 -> 共险 -> 有限合作 -> 更深层绑定

### 林野 x 韩季同
- 不是纯粹的正反派
- 是秩序机器对边缘人的持续压迫
- 韩季同既是威胁，也是照见城市秩序逻辑的一面镜子

### 林野 x 瞎灯匠
- 不要写成标准升级导师
- 他更像半真半假的引路人
- 说的话要有分量，但不能一次讲完

## 6. 卷一节奏卡

卷一不是大揭密卷，重点是“拉人入局”。

### 前段
- 先立住林野的现实处境
- 先让读者看见下层站区和主城之间的差距
- 用无灯列车做钩子

### 中段
- 异常事件逐步升级
- 让林野意识到灯塔系统不是普通维保系统
- 让乔宁、韩季同、瞎灯匠三条线咬进来

### 后段
- 黑雨夜与地下残灯站台成为第一次大冲突场
- 把“林野和执灯人系谱有关”这件事推进到更接近确认
- 但不彻底揭开旧文明真相

### 章末要求
- 章末必须逼出下一步
- 不是“事情结束了”，而是“林野不得不继续往前”

## 7. 章节功能与张弛

《末站执灯人》不能一路只靠异常事件往前硬推。

卷一的章节功能建议按下面几类交替出现：

### 主推进章
- 无灯列车
- 遗迹入口
- 地下残灯站台
- 灯塔规则被触发

### 过渡章
- 黑雨后的修轨与补灯
- 站区流言扩散
- 伤后修整
- 处理现实麻烦与工活

### 关系章
- 林野和乔宁对账
- 韩季同施压
- 瞎灯匠说半句话，逼林野自己判断

### 日常章
- 站区生存
- 旧轨巡修
- 黑市交易
- 吃饭、休息、等雨停

这些不是水章，而是这本书“人味”和“世界真实感”的来源。

### 本书节奏要求
- 不要连续很多章都只推异常事件
- 每 `2-3` 章推进后，应该有 `1` 章负责缓冲、关系或日常
- 过渡章也必须完成至少两件事：
  - 消化前一章后果
  - 为下一轮推进做准备

## 8. 禁忌表达

下面这些东西会明显拉高 AI 味，或者让《末站执灯人》跑偏，后面写正文时尽量避开。

### 禁止滥用的句式
- “空气仿佛凝固”
- “某种说不清的感觉”
- “像一张无形的大网”
- “像命运在此刻露出獠牙”
- “仿佛整个世界都在……”

### 禁止滥用的动作反应
- 倒吸一口凉气
- 额角滑下一滴冷汗
- 心脏像被一只手攥住

### 禁止跑偏的类型腔调
- 过于轻佻的网文吐槽腔
- 过于工整的说明文腔
- 过于抒情的散文化空镜头
- 一章里连续很多段都只有气氛，没有人物选择

## 9. 这本书里哪些是通用，哪些是专属

### 可以升级到通用层的
- 章节功能类型
- 张弛节奏比例
- 章末逼迫原则
- “先立人再立事”的推进规则

### 只属于《末站执灯人》的
- 冷硬潮湿的废轨气质
- 林野的判断顺序
- 乔宁的说话方式
- 灯 / 轨 / 锈 / 雨这套意象系统
- 本书的禁忌表达和关系推进方式

## 10. 动态更新约定

这份卡不是一次定死的。

更新规则：
- 每写完 `3-5` 章，回看一次
- 从已经写出来的正文里反推：
  - 哪些文风是稳定有效的
  - 哪些人物声音成立
  - 哪些节奏最顺
  - 哪些表达该加入禁忌清单

如果某条规则反复无效，就把它改掉，不要硬留。

## 11. 视角与时间线约束

### 视角规则
- 卷一主体视角固定跟林野
- 可以短暂切到别的人物，但必须有明确功能：
  - 展示林野不知道的危险
  - 展示林野行为造成的外部影响
  - 拉开主城与站区的层级差
- 不能为了花样随便切视角

### 时间线规则
- 卷一前段尽量让时间连续可感
- 每次黑雨、封轨、问询、下旧站台这类关键事件，都要让读者大概知道前后顺序
- 不要随意跳天数，除非章节里给出足够过渡

## 13. 使用原则

- 这份卡只约束“方向”和“味道”
- 不要把它写成机械模板
- 真正落笔时，优先保证人物活、冲突实、信息推进自然
- 写完后再回头检查有没有跑偏

## 14. 元语言阶段说明腔禁忌

- 不要在正文里直接写“卷一后半段”“卷末真正要做的是”“第四阶段开始以后”“整本书到这里”“下一组 / 下一阶段”之类的话
- 这类内容只能写在大纲、复盘、协议文件里，不能写进角色视角正文
- 林野、乔宁、韩季同可以判断局势，但不能替作者总结章节管理结构

## 15. 当前批次写后扫描

从现在开始，正文每写完一批，立即执行一次：

```powershell
npm.cmd run writing:meta-check -- --dir books/末站执灯人/02-正文 --from 起始章号 --to 结束章号
```

先扫当前批次，再决定要不要继续下一批，不把同类问题拖到全卷回扫时再处理。
