# 第147章：第一盏越班亮起的灯

封表后的第一夜，比谁想的都难。

因为南段那边还没递班，东环却开始不安分了。

守到后半夜时，东环值守廊最里那盏本该等到换班后才回亮的边灯，忽然提前亮了一瞬。

不是大亮。

是火心猛地一挑，像有谁提前把下一班的灯气拨上来了一口。

老顾当场就骂：“越班了！”

林野也立刻站了起来。

东环这些夜好不容易才把递班顺序跑稳，最怕的就是这种还没换到下一轮，灯先自己认了后面的位。

这说明下面那一层在催。

催什么？

催他们别再只守东环。

南段那边一旦开口，旧轨整段要的就不再是一张表守一口，而是多口之间按顺序递班。东环这盏灯提前越班，本质上是在问：

你们打算什么时候把南段也接上？

顾小石被那一跳吓得手一抖，险些把油壶碰翻：“要不要压掉？”

“不能硬压。”乔宁盯着灯心，“硬压它就会改从别的口要。”

林野没急着动灯，先去看表。

东环递班的那条线最末端，本来该在寅初后半才转白。可现在，最后一格边上多出一条极浅的细意，正往南缝那道空白轻轻搭过去。

它不是乱。

它是在越位接南口。

林野一下就明白了。

封表不是白封。

但旧轨不会因为你封着不递，就停下来等你慢慢商量。它只会先在已经跑顺的地方，把后面的需求往前顶。

换句话说，南段的灯已经开始借东环的班在醒。

这要是继续放着不管，东环迟早会被借穿。

老顾还在骂：“再这么弄，东环就得先断！”

“不会先断。”林野把表往回一压，“它现在还只是在试一盏。”

“试什么？”

“试我们能不能看出来，这不是东环自己的灯。”

乔宁立刻接上：“那就别拿东环的灯位去喂它。”

林野点头，转身就让顾小石去后巷搬那盏昨夜刚稳住的残灯备用罩。

不是换灯芯。

是把东环这盏提前越班的火，借罩压住，让它只能往上挑，不能往外串。

同时，他让梁四隔着门报了一次“归口”，却不是报东环，而是按昨夜从交班房抄出来的旧位次，低低报了一个：

“南二待接。”

这一声刚落，东环那盏挑起来的火心竟真的停了一停。

它没灭。

只是没再继续往外走。

老顾看得眼睛都直了：“这也行？”

乔宁在旁边低声说：“它不是要东环多出一班。它是在问，南二那边是不是已经有人准备接。”

站区还没排出第一张南段表。

可他们至少得先让旧轨知道：这边不是完全没回应。

于是这一夜，林野他们第一次做了一件很奇怪的事。

没正式递班进南段，却在东环这边先替南段报位。

东环守的是自己的口。

嘴上报的，却是南段那边还没写出来的班。

这感觉很怪，也很险。

像拿一条刚学会走的腿，去替另一条还没长好的腿借力。

可旧轨偏偏吃这一套。

那盏越班亮起的灯没再继续往上蹿，只在后半夜缓缓退回原位，像接受了“那边有人知道你在要什么”这个说法。

天快亮时，站务房里几个人脸色都不太好看。

不是因为守不住。

是因为他们都意识到了一件更沉的事。

南段再不开第一张表，东环迟早会被后头的灯一盏盏借过去。

你可以拖一夜，两夜。

拖不了一整段旧轨都醒。

韩季同天亮前来了一趟，听完昨夜怎么处理的，脸色比平时更黑。

“主城那边也看见了。”他说。

“看见什么？”

“东环凌晨有一盏灯越班上挑。”韩季同看着林野，“监测房那边已经把这算成正式异动，不再当站区局部波动。”

顾小石气得直拍桌子：“那我们昨夜替他们压住了，他们还当成自己的监测成果？”

韩季同没理他，只继续说：“黑市那边更快，早上已经有人在外头放话，说南段第一盏灯快醒了。”

林野听到这里，反而心里彻底稳下来。

事情到这一步，再想慢慢拖已经不可能。

真正的争夺已经被这盏越班灯提前点了火。

不是他们愿不愿意开的事。

是再不开第一张南段表，东环就要替整段旧轨继续扛债。

韩季同看着桌上那张被压住的守灯表，忽然问：“你现在还想先摸几夜再写？”

林野摇头。

“不等了。”

乔宁侧头看他：“你想好了？”

“嗯。”林野盯着那条从东环末格轻轻搭向南缝的白意，“今晚开始，先写南段第一张试守表。”

老顾骂了一句粗口，却不是反对。

他骂完以后，狠狠干了一口冷茶，抬头道：“那就写。再不写，东环这口迟早被它借空。”

这就是眼下最清楚的一刀。

不是他们想不想往前走。

而是第一盏越班亮起的灯，已经替整段旧轨把时间往前拨了一格。
