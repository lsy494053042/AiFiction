# 第122章：第一次排出来的守灯班

东环钟一响，站区第二天就乱了。

不是因为所有人都知道那钟后面有什么，而是因为所有人都知道，只要旧轨开始一处一处醒过来，守灯这件事就再不是林野一个人能顶住的了。

老稳压井要盯。

东二后巷那盏残灯要盯。

东环废站的旧检票钟后面，现在又多出一道不知道什么时候会彻底开的门。

一夜之间，站区一下从“有异常”变成了“要排班”。

韩季同把人叫到桥边旧站务房时，屋里已经先吵起来了。

来的人不多，都是站区这些年还能算得上有手有脚、有胆量又多少碰过灯线的那批人。补灯员、搬线工、夜巡的、旧桥底下守泵的人，全挤在一张发黑的大木桌边，脸上都是一副“谁也别想先把我推出去送命”的表情。

“我先说清楚，”最先开口的是守泵的老顾，“盯灯可以，别把命直接算进去。我们以前守的是泵，是桥，不是这些会自己认人的东西。”

“你不守，谁守？”另一个搬线工立刻顶回去，“等主城把静灯组全塞进来？那以后站区连谁晚上能回家都不是自己说了算。”

“那也不能随便排人下去！”

“现在不是下去，是先把上面的班排出来！”

吵到后头，谁也不服谁。

乔宁站在窗边，冷眼看着这屋里的人争来争去，半晌才说了一句：“你们吵的是先死谁，不是先守哪一盏灯。”

屋里顿时安静了一下。

这句话太难听，却也太准。

林野一直没说话。

他在看桌上那几张被韩季同压下来的粗纸。上头是韩季同昨晚让人连夜抄出来的三处位置：老稳压井、东二后巷残灯、东环废站旧钟。每一处后面都空着值夜栏，像在等谁往上写名字。

这不是点名册。

是守灯表。

也是站区第一次真正意义上的值夜秩序。

韩季同等屋里消停了，才开口：“主城那边要在两天内给东环废站列重静。我最多压住四十八小时。这四十八小时内，站区自己要是排不出第一班守灯人，以后就别指望还有自己守的份。”

有人低声骂了一句。

可没人反驳这话。

因为大家都知道，韩季同说的是实话。

前头那次点灯之后，主城只是在试探。现在东环钟一响，他们就不会再给站区慢慢摸索的时间。

林野这才把手按上那几张纸。

“不往下排全人。”他说，“先排班，不先排死。”

老顾抬头：“什么意思？”

“意思是先把活分清楚。守井的守井，盯灯的盯灯，跑口的跑口，报信的报信。不是谁名字写上去，谁就得一头扎进钟后面。”

他一边说，一边在粗纸上划出四栏：

- 看灯
- 守口
- 跑线
- 递班

“老稳压井和后巷残灯，先归看灯。”

“东环废站钟口，先归守口。”

“北环和水塔后那条外线，得有人跑着看，归跑线。”

“一旦有口子开了，谁能补上、谁能把前一班换下来，归递班。”

这一下，屋里的人终于没再一股脑对着“下去谁”发火。

因为林野把“守灯”拆成了几件活。

活一拆，人就不再只看成送命。

乔宁看了他一眼，神色比刚进屋时缓了一点，却还是问：“那东环钟口如果今晚再开，谁先守？”

“我先去。”

“你去，不算班。”老顾立刻说，“你现在是灯认的人，不是普通班。”

林野抬头看他：“那就算临值。”

韩季同在旁边冷笑了一声：“你倒会给自己另起名。”

林野没理他，只继续往下写。

最终排出来的第一张守灯表，没有太多人名。

只有八个。

看灯两人，守口两人，跑线两人，递班两人。

其中真正能靠近东环钟口的，只有林野、乔宁和守泵老顾三个人。

静灯组的人一开始不同意。

在他们看来，这张表太散、太松，不像主城那套“定人定点定责”的方式。

韩季同却没替他们说话。

他站在一旁，看着林野把最后一个名字写上去，才淡淡说：“先让他们自己排一次。真排不起来，我再接。”

这话说得很轻，却等于给了站区第一口气。

乔宁盯着那张表，忽然问：“为什么把我放守口，不放跑线？”

“跑线得快，守口得稳。”林野说，“你适合稳着看人，不适合沿外线来回冲。”

“你倒替我定得明白。”

“不然呢？”

乔宁盯了他两息，没再顶。

老顾却还在看那张表最下面空出来的一行。

那一行什么都没写，只留着一道横线。

“这行留给谁？”他问。

林野说：“留给补缺。”

“谁补？”

“谁先被这条线认进去，谁补。”

屋里的人听到这话，脸色都不太好看。

因为这句话的意思大家都听懂了。

这张守灯表不是排完就稳了，后面还会有人被旧轨自己拽进来。

主城会加人，黑市会塞人，旧轨自己也会认人。

这是第一班，不是最后一班。

外头快到傍晚时，韩季同把那张粗纸拿起来，亲手按在站务房门后的公告板上。

纸不大，字也不工整，边角还沾着昨晚的旧泥。

可它一钉上去，站区那些围在外头偷看的人都安静了。

因为这是这地方第一次，不是按主城口令，不是按黑市出价，而是按自己的人和自己的活，排出一张守灯班表。

乔宁出门时，忽然伸手在最下面那道补缺横线上弹了一下。

“你信它真会自己把名字补上？”

“我不想信。”林野说，“但它已经在这么干了。”

乔宁没再说什么。

她只是回头看了一眼公告板上那张纸，眼神里第一次不全是防备，更多了一点像是在认账的东西。

天黑前，东环废站那边又远远传来一声钟响。

不大。

却够让整张刚贴出去的守灯表，在风里轻轻抖了一下。
