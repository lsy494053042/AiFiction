# 卷一复盘：无灯列车

## 一、复盘定位

这份复盘不再重写剧情，而是确认卷一有没有完成该完成的事，哪些地方已经跑顺，哪些问题要明确带到卷二前解决。

卷一当前结果：

- 已完成第 `1-100` 章
- 已完成卷一第一次真正的站台点灯
- 已完成“新的执灯信号”进入主城视野
- 已经证明《末站执灯人》这套题材和工作流可以往下跑

## 二、卷一目标与完成情况

### 卷一原始目标

1. 把林野从普通修轨工彻底推进主线
2. 把无灯列车、旧轨节点、执灯系谱正式绑成一条线
3. 让站区、主城、黑市三层秩序都开始围绕林野产生反应
4. 在卷末完成第一次点灯，让读者确认本书主卖点能兑现

### 完成判断

#### 1. 林野入局目标：完成

- 林野已经不可能再回到“普通修轨工”的位置
- 他不再只是撞上异常的人，而是被值守台、站台主灯、无灯列车共同认出来的人
- “先守灯，再追母亲”已经从口头判断变成实际选择

#### 2. 三线并线目标：完成

卷一末已经把这些线并到一起：

- 无灯列车
- 旧轨网络
- 补缺备账
- 裁名后账
- 林照溪错号
- 乔衡半签
- 甲三盒
- 残灯站台主灯

它们现在已经不是平行线，而是同一套秩序的不同入口。

#### 3. 三层秩序反应目标：完成

- 站区：已经被灯、借名、封线、冷柜、尸灯这些现实后果反复压实
- 黑市：不再只是消息渠道，而是真正在拿灯、名额和活路做生意
- 主城：已经从试探和封控，进入“确认新的执灯信号已经出现，但仍只肯待核”的状态

#### 4. 卷末兑现目标：完成

卷末已经完成：

- 林野下到地下残灯站台
- 值守台第二格亮起
- 站台重新来电
- 全城出现回响
- 主城收到“新的执灯信号”

卷一卖点已经兑现，不属于“只铺不爆”的开局卷。

## 三、卷一写对了什么

### 1. 现实代价是成立的

卷一不是只靠玄和规则撑着，站区现实后果写出来了：

- 借灯
- 冷柜
- 医棚线
- 封桥令
- 黑市名额
- 站区普通人的损失

这让整本书的异常线不空。

### 2. 人物关系没有完全工具化

目前最稳的三组关系：

- 林野 / 乔宁：从互试到共险，到值守台第二格真正并线
- 林野 / 韩季同：从秩序施压到一次真正开门
- 林野 / 瞎灯匠：一直保持“知道更多但不一次说透”的有效状态

### 3. 章节张弛基本成立

卷一已经证明：

- 主推进章能拉主线
- 过渡章和关系章没有完全变成水章
- 日常和现实后果章节确实能长“人味”

### 4. 卷末兑现足够硬

卷一不是停在“知道更多了”，而是落到了：

- 亮灯
- 救场
- 回响
- 被主城识别

这是有效卷末，不是知识性卷末。

## 四、卷一暴露出来的问题

### 1. 中段一度过于术语化

主要集中在卷一中段到后段前半：

- 签
- 账
- 补缺
- 值守台
- 裁名
- 临续

这些内容本身必要，但某些章节一度更像“查账推进”而不是“事件推进”。

### 2. 元语言阶段说明腔确实出现过

例如：

- “卷一后半段……”
- “卷末真正要做的是……”
- “第四阶段开始以后……”

这类表达已经证明会直接破坏沉浸，所以现在已经升级为全局禁忌，并加入写后即时扫描。

### 3. 人物热度仍有继续加厚空间

尤其是：

- 乔宁个人线还可以更独立，不只是情报位和第二值守位
- 韩季同可以继续增加他在秩序内部的矛盾和代价
- 林野后续要更明确体现“主动承担”的成长，而不是一直靠局势推着走

## 五、卷一已经回收的伏笔

- 母亲留下的灯芯不是纪念物，而是钥匙
- 无灯列车不是单点异常，而是旧轨系统入口
- 乔衡半签不是边线旧事，而是直接连着值守台第二格
- 林照溪留下的错号不是单独线索，而是点亮主灯前的关键回正条件
- 甲三盒不是资料盒，而是把备账、签线和站台主灯接起来的关键物件

## 六、卷一保留下来的未解问题

这些要带到卷二：

1. 无灯列车为什么认林野
2. 主城为什么只肯承认“待核”，却不敢先否掉新信号
3. 姚木生、闻绍平背后还有谁在继续维护旧账
4. 林照溪当年到底想把哪一格留给谁
5. 乔衡断在丙口外之前，到底知道了多少
6. 母亲立场仍不能真正讲穿
7. 地下站台只是重新来电，不代表整套旧轨秩序已经稳住

## 七、卷末角色状态

### 林野

- 已经完成第一次真正的站台点灯
- 已经被主城和旧轨共同认出
- 价值排序已经从“先求活”推进到“先守灯，再追母亲”

### 乔宁

- 不再只是带路和给消息的人
- 已经被值守台认进第二格
- 她和乔衡这条线后面必须真正往里掏

### 韩季同

- 已经不是单纯的秩序压力工具
- 他在关键时刻给了一次开门
- 卷二必须继续把他写在“秩序内部的灰度人”位置上

## 八、卷二必须继承的写作约束

1. 少查账，多现场
2. 多现实后果，不要让异常悬在空中
3. 继续用站区日常、修轨、守灯、换班长人味
4. 不再让元语言阶段说明腔进正文
5. 每批写完立刻跑 `writing:meta-check`
