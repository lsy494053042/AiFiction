# 卷二章节规划

## 执行规则

- 卷二继续按“大卷”推进，不再拆成短卷首。
- 阶段是规划单位，正文固定按 `10` 章一组落地。
- 每一组都必须同时兼顾：主推进、关系推进、现实后果、下一组入口。
- 每写完一组，立刻执行一次：

```powershell
npm.cmd run writing:meta-check -- --dir books/末站执灯人/02-正文 --from 起始章号 --to 结束章号
```
