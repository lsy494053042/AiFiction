# 第01章 0.7%电量的砖头和会呼吸的墙

福尔马林味混着新鲜铁锈味，像有人把两块脏抹布一前一后塞进周临鼻子里，狠狠干了一把。

他猛地睁眼，侧过身狠狠干呕，只吐出一口发酸的胆汁，顺着喉咙一直烧到胃里。

脚下是冰冷潮湿的水泥台阶，裤腿沾着半干不干的黏液，头顶那盏应急灯跟抽风似的，亮两秒，灭一秒，把整段楼梯照得像劣质鬼片取景地。灯一灭，楼道又像被谁把盖子扣上了，闷得连空气都带着肉味。

周临骂了句脏话，扶着墙想站起来，掌心刚按上去，后背汗毛“刷”地全炸了。

不对。

那不是墙。

墙皮底下软得离谱，像一大块还带体温的皮肉。他手掌一压，里面居然很配合地鼓了一下，像这栋楼隔着一层墙皮在慢慢喘气。

“行。”周临扯了扯嘴角，“别人穿越送新手村，我这边直接发活体凶宅，服务意识真够到位。”

话音刚落，眼前一花。

大片灰红色字符猛地铺开，像一台老电脑死前最后一次硬撑着开机：

`[主神空间（废弃）重启完成。]`

`[当前剩余能源：0.7%。]`

`[当前落点：高危异常节点。]`

`[警告：本地锚定持续受污染侵蚀。节点扩张后，空间将失去附着点。]`

`[警告：锚定崩解后，管理员同步失去庇护。]`

周临盯着那行“0.7%”，差点真给气笑了。

十分钟前，他还在城中村那间月租八百五的破出租屋里，对着房东发来的“再不交钱就把你被子扔出去”装死。十分钟后，他人到了这栋鬼楼，脑子里多了个废弃主神空间，顺手还成了最高权限管理员。

别人穿越拿系统，像进厂报到；他这回更像半夜在二手手机店捡到一块翻新机，开机一看电量只剩百分之零点七，壳裂了，售后炸了，最要命的是这破玩意儿还跟他命连在一起。

周临闭了闭眼，把刚灌进脑子里那堆破信息重新理了一遍。

眼前这个异常节点要是继续长，主神空间会先断锚；空间一断，他这个刚绑上去的黑户也得跟着报废。

不是他愿不愿意接盘，是这口棺材已经开始给他量尺寸了。

楼下忽然传来一声轻响。

“啪嗒。”

像有什么黏糊糊的东西拖着自己，顺着台阶边缘慢慢蹭过去。

周临呼吸一顿，下意识屏住气。几乎同一时间，耳边那些杂音一股脑全冒了出来。有人哭，有人笑，有人像在贴着他耳朵念祷文，还有一堆分不清男女老少的音节，顺着骨头缝往脑子里拱，像拿生锈钉子一点点往里钉。

他太阳穴突突直跳，眼角疼得发麻。

灰字再次跳出来：

`[检测到高维游离注视。]`

`[建议：启动最低限度存在压低。预计消耗：0.1%。]`

“这还用建议？”周临额角青筋都在跳，“赶紧开。再慢一秒，我都要被看成灯牌了。”

字一闪，那股压在他头顶的恶意暗了下去。

不是没了。

更像有人把追光灯从强档拧成了省电模式，还是照着他，只是没那么容易一眼把他从黑里抠出来。

周临靠着墙缓了口气，顺手把这块破空间还能动的家底清了一遍。

真正能用的，也就五样：最低限度的存在压低，基础侦测，契约投放，认知滤镜，简易结算。没商城，没大招，连个像样的新手保护都寒酸得像拼出来的。周临给它下了个精准定义：“好消息，有挂。坏消息，挂像破解版，还自带低电量和木马弹窗。”

他贴着楼梯拐角，小心往下探了一眼。

这一眼，让他胃里那点酸水差点又翻上来。

三楼和四楼之间的平台，已经不算楼道了。

平台中央鼓着一团半人高的肉瘤，像脂肪、肠膜、血管和眼球被人拿粗针大线胡乱缝成一坨。每跳一下，表面都会裂开几个细小气孔往外喷白汽。十几根半透明肉丝从住户门缝里爬出来，一路扎进那团东西里。

肉瘤前面站着个披灰袍的人。

那人一只手按着肉瘤，嘴里低低念着什么，声音不大，却磨得人牙根发酸。灰袍底下时不时鼓起细长轮廓，像有活物在皮下慢慢爬。

再外一圈，是十几个住户。

有人穿睡衣，有人拎着菜篮子，有个胖男人甚至只套了一只拖鞋。每个人后颈都贴着细肉丝，眼神空得像死人，嘴唇一张一合，跟着灰袍人一起念。有人腿都软了，还是被那些肉丝吊着不倒。

灰字悄无声息浮出来：

`[低阶污染节点。主持者：未完全异化眷属。]`

“低阶你大爷。”周临压着嗓子骂，“你们这套危险分级是不是拿命名的？”

骂归骂，局还得自己试。

他抬起手，对着离自己最近的一根肉丝轻轻一划。

指尖前方闪过一道细得几乎看不见的灰线。

“嗤。”

那根肉丝当场断开，掉在地上以后像被扔进热油里的虫子，疯狂抽了两下，才慢慢发黑。

周临心里刚冒出一句“有用”，整栋楼就跟着抽了一下。

墙里的东西一起鼓起来，楼下那团肉瘤猛地涨大一圈，白汽一下浓了。更糟的是，刚被压暗那股恶意像是重新抓到信号，隔着不知道多远，冲着他脑子就是一锤。

周临眼前一白，鼻腔一热，差点直接跪在台阶上。

楼下那个灰袍人也慢慢偏过头，朝楼梯口这边看了一眼。

周临立刻缩回阴影，后背瞬间湿透。

懂了。

不是不能碰。

是不能拿这点家底直接去戳节点本体。

这跟用手机最后一格电开闪光灯抓鬼差不多，鬼抓没抓到不好说，自己肯定先亮。

周临抹掉鼻尖那点血，重新探头往下看。这回他没再盯那团肉瘤，而是先去看那圈祭品。

大部分人都快空了。

只有最外侧那个男人还在挣。

三十来岁，短发，夹克被扯烂了半边，右手腕被肉丝勒得发青，人却一直在找角度发力。更关键的是，他不是只顾着自己脱身。每次发力前，他都会先看一眼旁边那个快站不住的老太太，肩膀也在一点点往那边挪，像是准备硬撞过去替人拦一下。

就在这时，平台边上一个中年男人膝盖一软，整个人被肉丝猛地拖向中央。人刚碰到肉瘤表面，那层外皮就像水一样塌进去，转眼吞了他半条胳膊。

男人惨叫了一声。

最外侧那个短发男人眼睛一下红了，右肩狠狠干出去，想扑过去拽人。肉丝瞬间收紧，勒得他脖颈青筋都炸出来，可他硬是没垮，还借着这一撞又往旁边挪了半步。

灰字滑出来：

`[陈默，31岁。]`

`[市局刑侦支队。休班。]`

`[精神阈值：高。]`

周临目光一偏，又看见他脚边摔着一本半开的蓝皮记录本，纸页被血糊住大半，但还能看见几行没完全晕开的字：

福安里十七号。

失踪人口。

口供矛盾。

一下就对上了。

这人不是半夜路过撞鬼的倒霉蛋。

他本来就在查这栋楼。

也正因为他是这种人，到现在脑子还没彻底垮，手脚也没停，甚至还能想着去挡旁边那个老太太。

周临盯着楼下越来越快的仪式节奏，只用两秒就把账算清了。

他现在缺的，不是一个听话的木偶。

他缺的是一只手。

一只够硬、够清醒、能替他冲在明面上，还能顺着现实世界继续往下查的手。

陈默正好。

灰字再度浮出：

`[检测到高适配个体。]`

`[是否投放最低限度庇护协议？]`

楼下那团肉瘤又鼓了一次。

这回，连楼道天花板都跟着簌簌掉灰。

周临盯着那个还在死撑的刑警，抹了把鼻尖上的血，低声说：

“行吧。”

“今晚这张门票，算你命硬。”
