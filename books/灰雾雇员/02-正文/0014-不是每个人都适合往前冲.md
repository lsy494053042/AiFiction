# 第14章 不是每个人都适合往前冲

邓秋红那口气差点没提上来。

许宁动作快得像条件反射。

氧气面罩一扣，床头抬高，手往颈侧一探，再把刚配好的药往里推。整个过程她连一句“别慌”都没说，因为这时候说那话就是浪费气。

陈默站在边上，只能看着。

他能摁住发疯的人，能记动线，能追车，能拔枪。

可真碰到这种“人快不行了，但不是因为常规病”的局面，他伸手比不伸手更容易添乱。

这个认知让他脸色很难看。

不是丢人。

是窝火。

以前查案，窝火是因为证据断了。

现在窝火，是因为他第一次真切地意识到，有些活不是你硬就能顶。

脑子里那道声音像是专门挑人不爽的时候开口。

“懂了没？”

陈默把牙关咬紧：“懂什么？”

“不是每件事都适合你往前冲。”

“你少在这时候装老师。”

“我不是装。”对面口气平得要命，“你现在往前冲，只能把这间诊室再撞翻一遍。她该做的活是稳人，你该做的是让这东西别有机会继续开。”

这句说得不讨喜。

但没错。

许宁把邓秋红那阵抽搐压下去以后，摘掉手套，转身先去洗手。水龙头开得不大，水声细细的，反而把诊所里那股混着药味和黑灰味的空气衬得更闷。

她洗完手，直接在走廊尽头给陈默让了个位置。

“说吧。”

“你那个病案室的人，靠得住？”

“靠不住我不会提。”许宁从口袋里摸出手机，“他叫罗川，区医院病案室，平时兼医保审核和药房盘库。前两年他被一桩脏事擦过边，后来像是被哪边单独挂了个外围身份，具体他不说，我也懒得细问。毛病很多，但有一个好处，凡是数字和表格撒过的谎，他能闻出来。”

“你跟他什么关系？”

许宁看了他一眼。

“大学同学。”

“交情好？”

“一般。”她面无表情地回，“主要是我知道他研究生那年拿我的病例模板改过作业，他欠我。”

这话一出，陈默都愣了半秒。

不是因为好笑。

是因为太像她这种人会说的话了。

不卖惨，不煽情，不跟你讲什么朋友义气，直接把能用的旧账搬出来。

许宁低头翻通讯录，边翻边说：

“我可以帮你把人稳一会儿，也可以帮你看这些症状到底在往哪边走。但我先说清楚，我不冲前线，不跟着你们到处抓鬼，也不负责相信你那些没法写进病历里的东西。”

“那你负责什么？”陈默问。

“负责让活人别先死在‘你们快查出来了’之前。”

她把手机拨出去，抬眼又补了一句：

“陈警官，这种活本来就不该让一个人全顶。你要是还想一肩膀扛到头，最后不是你先废，就是病人先凉。”

陈默没说话。

因为他知道这句也对。

走廊那头，小姑娘蹲在椅子边，眼泪已经哭干了，抱着自己胳膊发抖。老保安拿着一次性纸杯给她接热水，接了半天热水都没满，还是一直守着。

诊所里所有人都在做自己擅长的那一块。

只有他刚才脑子里还在想着，要不要自己顺着线再往上冲一步。

电话接通了。

那头传来一个男人带着困意的声音，冷冷清清的，像从文件柜里冒出来。

“你最好是真要死了。”

许宁回得比他还冷。

“我没死，病人快了。”

对面沉默两秒。

“说。”

许宁把情况压成最短的话。

“女，四十六，胸闷幻听，接触过白事安抚物，症状异常。我要你帮我把她近一个月病历、药单、社区回访记录，还有和福安里、河埠头相关的白事物流、药店购买和陌生来电重新并一次。”

“关键词？”

“静目，香灰，符纸，安魂包，失踪案，白事用品。”

对面又安静了一下。

这回不是困。

像是在脑子里过了一遍他要怎么开口骂人。

最后他只问：

“你现在在哪？”

“福泽社区卫生服务站。”

“二十分钟。”

电话挂了。

陈默听完整个过程，终于知道许宁说的“毛病精”是什么味儿了。

这人还没露面，声音已经先把脸立起来了。

少情绪，少礼貌，先要关键词，先要能对上的信息，像根细长的针，不是拿来扎人的，是拿来挑线头的。

脑子里那道声音慢悠悠来了句：

“这回像样了。”

“什么像样了？”

“岗位。”

陈默这回没怼。

因为邓秋红就在里头，许宁在稳人，门外小姑娘和老保安在守，新的那个人正在赶来，而他终于不必再自己去干全部的活。

这不是舒服。

只是终于稍微像回事了。

许宁把手机塞回口袋，靠着墙，闭眼吐了口气。

她这会儿脸上疲色压不住了，白大褂肩线也有点垮，可语气还是稳的。

“还有一件事。”

“你说。”

“那只灰布包，我刚才挪远以后，她症状确实缓了一截。”许宁抬眼看向观察室，“这说明问题不只在人身上，也在那东西身上。你们后面要处理它，可以。但别在我诊室里乱来。”

“什么意思？”

“意思就是，这里有活人，有药，有氧气瓶，还有一个哭得快晕过去的家属。”她一字一顿，“你们要是真准备今晚在这儿跟什么鬼东西狠狠干一架，那先把我和病人安排好。不然第一个先收拾你的，不是鬼，是我。”

陈默嘴角终于动了一下。

“行。”

“这话我记着了。”

许宁没搭理他，转头进了观察室。

她刚走进去，邓秋红床头那台老监护仪就“滴”地一声轻响。

数值没往坏里跳。

可治疗车底那只灰布包，像是听见了什么信号，布下面忽然微微一鼓，拉出一个很轻的弧度。

像有人在里面，隔着布，慢慢把头抬起来了。
