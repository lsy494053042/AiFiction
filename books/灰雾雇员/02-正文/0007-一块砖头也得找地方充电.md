# 第07章 一块砖头也得找地方充电

周临找到临时落脚点时，已经是上午九点。

地方是旧城公寓两条街外的一间日租房。

房间小，窗帘发黄，床垫塌了一半，墙角还贴着前任租客留下的外卖优惠券。唯一的优点是便宜，押金能商量，房东不问人从哪来，只问钱什么时候到。

周临坐在床沿上，看着自己手机里仅剩的余额，觉得世界对穷人的想象力一直很稳定。

穿越前穷。

穿越后还是穷。

唯一升级的是，现在穷得更有层次了。

现实里没钱，脑子里那块破空间也没电。

他闭上眼，调出主神空间的基础状态。

`[剩余能源：0.34%。]`

`[当前可用：最高权限绑定 / 基础任务生成 / 低级雇佣契约 / 低级结算 / 极低精度感知。]`

`[不可用：兑换库 / 训练场 / 空间仓储 / 样本解析库 / 跨界投放。]`

周临看完，沉默了很久。

好消息是，这东西确实不是普通系统。

坏消息是，它现在表现得很像一块贴着“曾经很贵”标签的砖头。

旧城公寓那一战救回了一点能源，也让基础任务和结算勉强跑起来。但那点回升远远不够。别说兑换技能、开训练场，连稳定维持远程感知都得掰着指头算。

而且周临已经试过。

他不能离旧城公寓那个锚点太远。

距离一远，脑子里的空间状态就开始掉帧，像破无线网隔了三堵承重墙。再远一点，那股被污染盯上的凉意又会浮上来。

换句话说，他现在不是想苟就能苟。

他得先让这破空间有电。

还得让陈默这根前线针，顺着旧城公寓扎出去。

周临揉了揉眉心。

主神空间给出的任务生成很粗糙，不会告诉他“请去某某地点打某某怪，奖励某某宝箱”。它只能根据已知线索、污染残留和雇员状态，拼出一个可执行目标。

对陈默来说，那是任务。

对周临来说，那是活命路线。

他也不是没想过再招一个人。

问题是招人不是路边扫码送鸡蛋。

高维雇佣契约能把人拉进体系，也会消耗能源，还得承担对方身上的雾痕稳定。随便把普通人拖进来，短期看像多了双手，长期看就是多了一张嘴、多一份风险、多一个可能把组织卖给别人换命的缺口。

陈默这种，是被旧城公寓直接卷进去，又能在祭场里保持判断的人。

这种人可以赌。

普通人不能这么赌。

周临把这个念头按下去，在心里给自己记了一条：以后招人要有门槛。

不是谁撞见异常，谁就自动进来。

能活、能做事、能承受真相，还得有留下来的理由。

他把旧城公寓回收的黑色香灰、灰袍主持者残影、住户后颈雾痕，还有“静目香烛”这个关键词重新过了一遍。

然后他生成了第一份正式任务。

`[任务：追查旧城公寓污染来源。]`

`[目标一：确认“静目香烛”与旧城公寓事件关联。]`

`[目标二：获取可提交样本或有效线索。]`

`[提示：本任务不提供行动攻略。]`

这就够了。

再多就是装懂。

陈默不是摄像头，也不是游戏角色。他知道怎么查案，知道怎么绕程序，知道什么地方该问人，什么地方该先看监控。

周临要做的是给他一个方向、一个结算理由、一点污染稳定。

剩下的得让他自己跑。

任务投放出去后，周临往后一倒，瘫在塌了一半的床垫上。

床板“吱呀”一声，像在替他叹气。

他盯着天花板上那块发霉的水印，忽然笑了一下。

现实问题也不比异常温柔多少。

他需要钱，需要稳定住处，需要不被房东一天三催，需要能放样本、藏东西、临时接人的地方。主神空间再高维，现在也不能给他变一张免房租证明。

组织经营听着气派。

落到第一天，就是先别睡桥洞。

周临摸出便利店买的饭团，咬了一口，米粒冷得像小石子。

他嚼了两下，心想这大概就是创业。

只不过别人创业烧投资人的钱。

他创业烧自己的命。

主神空间内部也没好到哪去。

周临试着往里看过一次。那里没有想象中的白色大厅，也没有整排光球和兑换屏幕，只有一片像断电商场一样的黑。远处偶尔亮一下，像有什么旧设备在深处喘气。

它以前可能真的辉煌过。

但现在，辉煌被拆得只剩骨架。

周临要做的不是坐在王座上发号施令。

是先把电闸找到。

再想办法别被电闸电死。

这要求听起来不高，执行起来很寒酸。

“主神空间。”

这四个字听起来多气派。

真正落到他手里，却是住日租房、吃便利店饭团、拿 0.34% 电量赌命。

但周临没有真的丧太久。

旧城公寓压住了。

陈默活下来了。

任务能发，结算能跑，雇佣契约也能生效。

这说明破归破，它不是纯摆设。

只要不是纯摆设，就有活路。

手机忽然震了一下。

是房东发来的消息。

“续住的话下午五点前转账，不续就退房。”

周临看完，面无表情地把手机扣在床上。

很好。

现实也在催命。

他闭上眼，重新接入陈默那边的任务频道。

“陈默。”

那边隔了两秒才回。

“说。”

“静目香烛。先从它查。”

“我已经在路上。”

周临睁开眼。

这人有时候确实省心。

省心得不像员工，像债主。
