# 当前批次章纲-第04批

## 批次范围

- 章节范围：`0027-0036`
- 批次定位：卷二起手组
- 批次任务：把“安宁苑三号楼”从一个地址写成一条正在运转的居民区补人线，同时逼出第一层临时落脚、观察、轮班和现实承接需求，让卷二真正立起新问题。

## 批次必须兑现

1. 安宁苑三号楼必须被证实不是单户事故，而是一条正在筛人、补人、点名的居民区补人线。
2. 陈默、罗川必须把卷一带出来的名单、编码和现实住户情况第一次并起来，锁出几名高危目标。
3. 许宁必须进一步站进“先保活人，再谈规则”的位置，不再只是跟着救火。
4. 活人救出来以后“往哪放、怎么盯、谁来接”这些现实问题必须正面出现，不能再被一句话带过。
5. 第一处更稳的临时落脚点必须被补出来，样本、物资、临时收容和观察位第一次有地方落。
6. 第一版像样的轮班、守点和交接必须开始出现，岗位要第一次压过“谁狠谁顶上”。
7. 批次结束时，电话点名这层逻辑要被压实，安宁关怀这层现实壳要正式露头。

## 章节拆解

### 0027 安宁苑三号楼

- 功能：卷二开场、咬住卷一扣子、把新问题从一句短话落成一个具体地方。
- 核心内容：
  - 众人顺着卷一卷末账册末页和“乙字线损，补人”短句，摸到安宁苑三号楼。
  - 他们确认这里不是旧殡仪馆后街那种一次性后续事故，而是居民区里正在运转的新口子。
  - 陈默第一时间意识到，这回问题更脏，因为它混在最普通的楼栋日常里。
- 章末钩子：
  - 他们发现高危目标不止一户。

### 0028 名单先从活人看起

- 功能：信息并线、锁目标、把卷二第一批危险对象明确出来。
- 核心内容：
  - 陈默、罗川把卷一拿到的旧名单、编码、电话痕迹和安宁苑住户情况第一次并起来。
  - 罗川开始从“谁最像会先出事的人”反推补人逻辑。
  - 几名最危险目标被圈出来，卷二第一次有了能落到人头上的压力。
- 章末钩子：
  - 今晚最先发作的人被锁出来了。

### 0029 今晚先别让她回家

- 功能：卷二第一次抢活人、让许宁的岗位往前站。
- 核心内容：
  - 陈默抢在目标回家前先把人稳住，硬把这次处理从“事后捞人”改成“事前截人”。
  - 许宁第一次正面参与“先转移活人，再谈规则”的决断。
  - 目标人是救出来了，但她已经没法按原样回家。
- 章末钩子：
  - 人救出来了，却没地方长期安置。

### 0030 活人得有地方放

- 功能：把现实承接缺口正面拉出来。
- 核心内容：
  - 众人第一次被迫面对落脚点、观察位、临时收容和撤退接应的现实问题。
  - 许宁把“能把人从现场拉出来”和“能把人真正保住”之间的差别挑明。
  - 周临确认卷一那种临时借位已经不够用了。
- 章末钩子：
  - 旧的临时借位撑不到下一轮。

### 0031 借来的屋，不算站住

- 功能：关系承接、把“借地方”和“站住脚”之间的差距写实。
- 核心内容：
  - 众人围着临时借来的地方转一圈，第一次把“地方能不能保命”当成硬标准。
  - 许宁把借地方、看护、遮掩和风险这些账一条条摊开。
  - 岗位意识进一步从嘴上说说变成现实压力。
- 章末钩子：
  - 他们必须尽快补出一个更稳的现实壳。

### 0032 旧汽修厂后头的第二把钥匙

- 功能：补现实落点、让周临继续通过旧壳和人情账补出只有他能补的东西。
- 核心内容：
  - 周临顺着旧壳、人情和老鲍这条线，撬出一处能临时放人、放样本、放物资的小落点。
  - 这地方不体面，但足够让灰雾雇员第一次有个像样的“后手位”。
  - 新落点能用，却不是白给，旧账和后续条件一起压过来。
- 章末钩子：
  - 这地方能用，但得先认一笔旧账。

### 0033 先把班轮起来

- 功能：转场、复盘、第一次让轮班和交接真正站住。
- 核心内容：
  - 第一份像样的轮班、守点和交接方式开始出现。
  - 陈默、许宁、罗川、老岳各自开始有“我现在该守哪一口”的自觉。
  - 岗位第一次比谁胆大更重要。
- 章末钩子：
  - 第二户目标在同一夜里收到点名电话。

### 0034 电话不是来催命的

- 功能：继续压调查线，把电话从现象写成规则动作。
- 核心内容：
  - 罗川把电话、回访和发作时间线重新压实。
  - 众人确认电话不是单纯通知，而是补人链里的“点名动作”。
  - 他们顺着这层电话动作，摸到一层新的现实外壳。
- 章末钩子：
  - 电话背后露出一层新壳。

### 0035 楼上楼下都在等名

- 功能：抬高范围，把安宁苑从一户抬成同楼多户。
- 核心内容：
  - 众人发现安宁苑不是一户出事，而是同一栋楼里几户人在不同时间窗口被筛。
  - 陈默第一次直观看见“居民区补人线”比旧城公寓更像日常运转结构。
  - 同楼不同户之间的时间差，开始给罗川提供更完整的判断框架。
- 章末钩子：
  - 其中一名目标在他们眼皮底下失踪。

### 0036 谁把人从家里领走了

- 功能：卷二起手组收口，把更具体的现实壳抛出来。
- 核心内容：
  - 陈默顺着物业、家属和白事外包痕迹追人。
  - 他们确认有人能名正言顺地把目标从家里领走。
  - “安宁关怀”这层单子和现实身份开始露面，卷二问题继续往外抬。
- 章末钩子：
  - 一张“安宁关怀”单子浮出来。
